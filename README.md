## Projects

### 🏎️ JetBot AI 道路循跡與路牌辨識

**NTUT Multimedia Applications Final Project**

大學多媒體應用的期末專案。

使用 JetBot 實作自動道路循跡，並加入路牌辨識，最後把影像辨識、控制邏輯和實車整合在一起。

主要使用：

`Python` · `PyTorch` · `ResNet-18` · `YOLOv4-tiny` · `TensorRT` · `Jetson Nano`

專案中包含道路模型訓練、路牌辨識、PD 控制，以及最後的 JetBot 實車測試。

🔗 **[NTUT_Multimedia_Applications_Project_Final](https://github.com/Andy87877/NTUT_Multimedia_Applications_Project_Final)**
